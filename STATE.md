# STATE — macyad

Обновлено: 2026-11-24 (релиз 0.1.4)

## Зачем этот файл

Единственный вход в состояние репозитория: что здесь сейчас, что дальше, какие решения
приняты и что открыто владельцу. Грузится в начале каждой сессии импортом из `CLAUDE.md`.
Stop-хук `.claude/hooks/require-state-update.sh` не даёт закончить сессию, в которой менялись
файлы, а этот — нет. Handoff описывает одну сессию, этот файл — репозиторий целиком.

## Сейчас

- Последний релиз — `v0.1.4` (2026-11-24), выпущен тегом из `main`.
- В 0.1.4 (#35–#43): решения окна разбора пишут на Яндекс в написании папок, которое там
  уже есть (NFC/NFD); плановая синхронизация повторяет сбой сети сама; подтверждение, когда
  «Оставить remote» удалит файлы или затрёт локальные правки; Push All / «Проверить все»;
  прогон пишет только свой результат, не откатывая правки пары; журнал этапов запуска
  (`os.Logger`, subsystem `me.orloff.macyad`); свой индикатор запуска у каждой пары и честное
  «Следующая синхронизация».

  `/usr/bin/log show --last 6h --predicate 'subsystem == "me.orloff.macyad"'` и смотреть
  последний этап пары.
